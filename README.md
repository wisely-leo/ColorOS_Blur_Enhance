# ColorOS Blur Enhance

[![License: GPL-3.0-or-later](https://img.shields.io/badge/License-GPLv3--or--later-blue.svg)](LICENSE) [![Platform](https://img.shields.io/badge/Android-16%20(API%2036)-green.svg)](#-支持环境) [![LSPosed](https://img.shields.io/badge/LSPosed-libxposed%20API%20102-orange.svg)](#-支持环境)

为 **ColorOS 16** 的桌面、多任务、时钟组件、相册、全局搜索与输入法提供动态模糊 / 视觉增强的 [LSPosed](https://github.com/LSPosed/LSPosed) 模块，自带可实时调参的图形化设置界面。

---

## ✨ 功能

**桌面**
- **图标 / 文件夹模糊**：长按、拖拽、打开文件夹时按需叠加模糊，带渐进动画
- **桌面卡片模糊**：OPPO 卡片（耗电看板等）出现在桌面即自动挂上高斯模糊，无需手动触发
- **应用名阴影**：常驻柔和阴影，亮 / 暗壁纸下都清晰；卡片内标题同样适配
- **壁纸深度模糊**：接入桌面深度控制器，随桌面状态联动
- **时钟组件字形模糊**：时间 / 日期 / 天气文字与图标贴合字形轮廓模糊，支持自定义混色

**系统界面**
- **全局搜索**：搜索页背景透明化，透出桌面实时模糊（仅当下层是桌面时）
- **相册**：照片页强制浅色，不受深色模式影响
- **输入法**：键盘背景高斯模糊（仅适配语燕输入法）
- **多任务桌面模糊**：⚠️ 实验性，默认关闭

**设置界面**
- 双页结构 + 可折叠选项；改动经广播 + `blur.conf` 实时同步，无需重启或重装
- 检查更新（按 `versionCode` 语义比较）、作用域逐包重启（需 Shizuku）、自定义背景图

## 📱 支持环境

| 项目 | 要求 |
|---|---|
| 系统 | **Android 16（API 36）** |
| 框架 | LSPosed（libxposed API 102） |
| 桌面 | **仅 ColorOS / OPPO 系统桌面** |

**作用域（共 6 个，建议全选）**

| 作用域包 | 用途 |
|---|---|
| `com.android.launcher` | 桌面模糊、卡片模糊、应用名阴影、时钟组件模糊 |
| `com.coloros.alarmclock` | 时钟文字透明度 / 混色（含真我 realme 布局） |
| `com.oplus.blur` | 后处理模糊采样率适配 |
| `com.heytap.quicksearchbox` | 下拉搜索背景透明化 |
| `com.coloros.gallery3d` | 相册照片页强制浅色 |
| `com.yuyan.pinyin.offline.release` | 键盘背景模糊 |

> 桌面模糊需同时覆盖 `com.oplus.blur` 与 `com.coloros.alarmclock` 才完整生效。升级安装时 LSPosed 会保留旧作用域，若相册 / 输入法不生效请手动勾选。
>
> 已验证机型：OnePlus / OPPO PLC110（ColorOS 16.1，Android 16）。

## 🚀 安装

1. 安装 **LSPosed** 框架
2. 从 [Releases](../../releases) 下载并安装模块 APK
3. 在 LSPosed 管理器中启用本模块，作用域建议全选
4. 重启桌面（或重启系统），打开模块界面按需调整开关
5. 开关不立即生效时，可在「模块设置」中重启对应作用域（需 Shizuku）

**可选：Shizuku** —— 用于逐包重启作用域。不授权不影响模糊功能，只是少了便捷重启。

## ⚙️ 调参与文件位置

首选图形界面（改动实时生效）。也可直接写配置文件或发广播（参数均为字符串附加项，需带 `--user 0`）：

```bash
am broadcast --user 0 -a com.wiselyleo.blurenhance.SETCONF --es blur_max 48
am broadcast --user 0 -a com.wiselyleo.blurenhance.SETCONF --es mark "enter-recents"
```

其余调试参数（`scaleexit` / `scaleenter` / `gts` / `visenter` / `visexit` / `tint`）见 `FeatureFlags`。

| 文件 | 路径 |
|---|---|
| 运行时配置 | `/data/local/tmp/ColorOSBlurEnhance/blur.conf` |
| 模块日志（默认关闭） | `/storage/emulated/0/Download/ColorOSBlurEnhance_p<pid>.log` |
| 界面日志 | `/storage/emulated/0/Download/UiStartup.log` |

> 发布版日志默认关闭：不产生日志文件，也没有运行时开销。

## 🔖 版本历史

| 版本 | 说明 |
|---|---|
| **v47** | **新增「横屏应用过渡旋转」**：横屏应用退出时保持横屏，过渡动画中逐帧逆时针转 90° 落回竖屏桌面（进入反向），窗口与图标同步旋转、不裁切窗口。**修复横屏旋转整体不生效**：目标类名解析路径写错（实际位于 `systemui.shared.system` 下），安装期直接失败；安装过程改为独立隔离，不再牵连其它功能。**修复末尾渐变破坏过渡动画拖尾**：淡出改为与系统透明度曲线相乘，不再覆盖。**修复动画幅度大时末尾被提前淡出打断**：判据不再看进度，改为逐帧测实际位移与尺寸，确认停住才动手，并以固定角速度顺时针回正。**开关即时生效**：设置页关掉任意功能后宿主进程立即停止处理，「桌面卡片模糊」「应用名阴影」开关同样即时生效；修复部分开关改了不生效（配置写盘与实时广播统一为同一份键值表，广播解析改为通用路径）。**性能**：进度读取零分配、目标信息按动画缓存、反射次数由 6~7 次降至 3 次、两通道共享变换矩阵、收尾不再写调试日志。**修复内存滞留**：逐帧缓存强引用（含 `SurfaceControl`）主动清空。代码结构整理（行为不变），78 处静默异常改为可记录。**版本号规则**：版本号与版本码一一对应（v47→470，v47.1→471），末位到 9 后自动进位（479→480）。 |
| **v46.4** | **修复桌面卡片黑屏**（调整卡片大小后整窗变黑）：卡片重建时若目标已是模糊背景则跳过，避免模糊节点重复挂载；原生接口未替换背景时改为原样回滚，不再清空背景。**修正卡片底色层透明度判据**（CSS 底色层实测返回 `-2 / -3` 而非 `-1`，旧判据只认 `-1`，导致部分卡片选不中）。另有可维护性重构（零行为变化）与性能清理。 |
| **v46.3** | 新增「桌面卡片模糊」：卡片出现即自动模糊，仅处理已知卡片类并校验网格跨度；内容变化时自动重新处理，未就绪则指数退避重试。「应用名阴影」适配卡片内标题。 |
| **v46.2** | 新增「桌面应用名阴影」：常驻柔和阴影，恒为纯黑、只有浓度可调。修复键盘内发光观感。 |
| v46.1 及更早 | 发热与耗电优化、快捷菜单模糊修复、真我时钟适配、输入法键盘模糊、下拉搜索实时模糊、相册强制浅色、图形化设置界面等 —— 完整记录见 GUI 内「更新日志」。 |
